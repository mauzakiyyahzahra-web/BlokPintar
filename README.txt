BlokPintar - Dunia Game Edukasi 3D
==================================
Cara main: buka index.html di browser (Chrome/Edge/Firefox), bisa offline.
Kontrol: WASD/Panah jalan, Spasi lompat, E masuk portal, geser layar putar kamera.
Di HP: joystick kiri, tombol LOMPAT dan MASUK di kanan.

Isi: 25 game (6 Obby 3D, 4 Buru 3D, 6 Kuis, 2 Memori, 3 Urutan, Susun Kata, Robot Koding, Tangkap Jawaban, Ketik Cepat).
Skor bintang dan karakter tersimpan otomatis di browser.

Untuk mengubah soal: edit src/data.js lalu jalankan
  npm install
  node build.mjs
Hasil baru ada di dist/index.html
